# CalculIMC

Application Android en Kotlin permettant de calculer l'indice de masse corporelle (IMC).

## Configuration

- Android Studio
- Kotlin
- Minimum SDK : API 24
- XML Views
- Gradle Kotlin DSL

## Fonctionnalités

- Saisie du poids en kg
- Saisie de la taille en mètres
- Calcul de l'IMC
- Affichage avec deux chiffres après la virgule
- Interprétation du résultat
- Couleur selon la catégorie
- Validation des champs
- Bouton Effacer

## Formule

IMC = poids / (taille × taille)
